1. 初次找到瞳孔后，下一帧优先在上次瞳孔附近的 129×65 像素窗口统计暗区和计算中心。这样绿色大框内其他阴影不会直接拖动瞳孔中心。
2. 局部暗区如果很宽、很矮，宽度至少为高度 4 倍，并且高度不超过 28 像素，就判为闭眼；局部暗像素太少则判为无眼。以上是**待实板调节的起始阈值**。
3. 闭眼或无眼时隐藏粉色十字、清掉当前及上次运动方向、禁止文字移动。重新识别到眼睛后，方向模块重新记录起点。
4. 调试页的“更新”行后增加 `X` 和 `Y` 数值：分别是本帧暗区的**宽度和高度，十六进制**。这是调整闭眼判定的依据，不是瞳孔坐标。原“坐标”行仍显示瞳孔 X、Y。
